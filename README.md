# User Service

Консольное Java-приложение для управления пользователями. Для работы с PostgreSQL используется Hibernate без Spring.

## Возможности

- создание пользователя;
- поиск пользователя по ID;
- просмотр всех пользователей;
- обновление пользователя;
- удаление пользователя;
- проверка введённых данных;
- транзакции и откат изменений при ошибках;
- запись SQL-запросов и ошибок в лог.

Сущность `User` содержит поля:

- `id`;
- `name`;
- `email`;
- `age`;
- `created_at`.

## Используемые технологии

- Java 21;
- Maven;
- Hibernate ORM;
- PostgreSQL 17;
- SLF4J и Logback;
- Docker и Docker Compose.

## Требования для запуска

На компьютере должны быть установлены Docker и Docker Compose. Отдельно устанавливать Java, Maven и PostgreSQL для запуска через Docker не требуется.

## Запуск

Откройте терминал в каталоге проекта и запустите PostgreSQL:

```shell
docker compose up -d postgres
```

После того как контейнер базы данных перейдёт в состояние `healthy`, запустите консольное приложение:

```shell
docker compose run --rm user-service
```

При первом запуске Docker соберёт приложение и загрузит необходимые образы и зависимости.

## Консольное меню

После запуска доступны команды:

```text
1 - создать пользователя
2 - найти по id
3 - показать всех
4 - обновить
5 - удалить
0 - выход
```

Введите номер нужной команды и следуйте подсказкам приложения.

## База данных

PostgreSQL запускается в контейнере `user-service-postgres`. Hibernate автоматически создаёт или обновляет таблицу `users` при запуске приложения.

Данные PostgreSQL сохраняются в Docker volume `postgres_data`, поэтому они не пропадают после обычной остановки контейнеров.

Адрес `jdbc:postgresql://postgres:5432/user_service` рассчитан на запуск приложения внутри Docker Compose: `postgres` является сетевым именем сервиса базы данных.

## Логи

Логи приложения записываются в каталог:

```text
logs/user-service.log
```

Файл лога создаётся автоматически после запуска приложения.

## Остановка

Для остановки контейнеров выполните:

```shell
docker compose down
```

Эта команда не удаляет сохранённые данные PostgreSQL.
